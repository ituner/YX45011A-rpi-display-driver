# Reference hardware

`SCH_Schematic2_2026-04-21.pdf` is the unmodified adapter-board reference
supplied with this project. SHA-256:

```text
5d8ab0a5f3fdba6bf4f8dc7c40b4baca196a74cd3175ebae25cf249c2f17a548
```

Visual review shows a 22-pin, 0.5 mm-pitch top-contact FFC DSI input at CN2,
and a 30-pin display connector at CN1. The diagram identifies the LCD
controller as ST7701S and shows two DSI data lanes and a clock lane. It does
not specify panel timing or the manufacturer initialisation sequence.
